主流象棋 App 棋盘为 Canvas 自绘，无障碍树中无棋子节点，无障碍服务路线不通。识别采用 MediaProjection 截屏 + OpenCV 模板匹配：用户首次对接某 App 时执行一次性校准（框定棋盘、采集 14 类棋子模板），运行时按 9×10 网格逐点比对。换皮肤或换 App 重新校准约 1 分钟，换来识别模块从"ML 项目"降级为"纯 OpenCV 工程"，零训练、零数据集、速度极快。通用化检测模型（YOLO 等）作为未来可选优化保留，不当地基。

## Consequences

- 校准是产品内置流程，需在 UI 中作为一等公民对待
- 棋子动画/阴影帧可能匹配失败，需在局面变化检测中做容错与重试
