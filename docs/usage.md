# 使用文档

> 弈枰 · 实战悬浮助手。个人自用,不上架。
> 版本口径:2026-10-21 feature-cnn(方案 A,CNN 主路)。

## 0. 安装与启动

```
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

首次启动都会看到**墨纸编辑部级主界面**：报头「弈枰」+ 黑细线棋盘 +
右下角朱红大圆「开始实战辅助」。

| 主界面元素 | 作用 |
|---|---|
| 摆开局 / 清空 / 换先 | 摆盘工作台：恢复初始局面 / 清空棋盘 / 交换行棋方 |
| (擦除)+棋子名下拉 | 选画笔：选中后点棋盘空点即可摆子 |
| 校准 | 标定目标棋盘 App 的棋盘四角（首次必做） |
| 识别 | 截屏一次并进识别工作台核对模板 |
| 对局复盘 → | 查看历次封存对局的复盘明细 |
| 分析当前局面 | 对主界面棋盘直接做引擎分析,结果显示在底部结果卡 |
| 开始实战辅助（朱红大圆） | 启动/停止悬浮窗实战助手 |

## 1. 首次使用流程

1. **授权〈使用情况访问〉**(一次性):点「开始实战辅助」时若未授权会
   自动跳到系统设置页,在列表里找到「弈枰」并打开开关。该权限用于判断
   当前前台是否为 JJ 对局页(不读取内容),未授权时退回边条指纹启发式。
2. 点「开始实战辅助」→ 弹出截屏权限页 → 勾选后允许「立即开始」
3. **授权成功后悬浮窗自动出现**（局前只显示「开局」,不识别棋盘）;
   切到 JJ 对局后点「开局」才开始记账,不点不会识别、也不会弹识别提示。
   **Android 14+ 每次开启都要重新确认一次录屏**（系统限制）
4. 主圆钮是开关:运行中显示「停止实战辅助」,停止会释放投屏,再次开启
   需重新授权;停止/授权结果都有 Toast 提示

> ⚠️ 重装 APK 或杀进程后截屏授权失效,需重走第 2 步(系统限制)。
> 重装后的旧棋谱/FEN 会自动清空,不必再手动点「结 & 下一局」。
>
> 若点按钮只弹「授权后请再点一次此按钮」,说明服务已在但投屏未重启:
> 再点一次按钮会先停掉旧服务并重启授权流程。

## 2. 校准（每个目标棋盘 App 一次）

1. 点「校准」→ 3 秒倒计时内切到 JJ 对局界面（棋盘完整可见）
2. 自动抓屏后弹出悬浮「校准」按钮,点击进入标定页,依次点棋盘四角
3. 保存后自动做棋盘线吸附精化;结果存 `files/calib_default.json`

校准过的 App 之后无需重复。若识别出现**单格持续误读**（其余全对）,
优先怀疑校准文件坏了而不是识别算法——删掉重校。

## 3. 对局中使用悬浮窗

悬浮窗默认停在棋盘下方中央（避开识别区）,可拖动。

- **标题栏（局前）**：`弈枰 | 红/黑 | 开局 | ✕`
  **标题栏（局中）**：`弈枰 | 红/黑 | 暂停 | 纠 | 实 | 结 | ✕`
  **标题栏（已暂停）**：`弈枰 | 红/黑 | 继续 | 纠 | 实 | 结束 | ✕`
  点「红/黑」可手动翻转执方（一般是自动识别的,识别错时才用手动）;
  **点「开局」以当前盘面作为新局起点、清旧谱并重出推荐**,点后「开局」
  消失,只剩「纠/实/结」;点「纠」输入实际走子纠正识别;点「实」看棋谱/
  识别对照;点「结」封存并复盘,按钮依次为 `结 → 复盘中 → 复盘X/Y`，
  复盘完成后回到局前态（只剩「开局」）。
  **暂停（2026-10-26）**：点「暂停」停止采集与推荐（省电、方便切 App 或
  用 JJ 沙盘），棋谱与投屏保留；点「继续」以当前盘面重同步——**暂停期间
  的走子不记账**（悬浮窗提示"已重同步"）；点「结束」= 封存并复盘。
  标题栏空白处点一下收起为小圆点,再点圆点展开。悬浮窗默认贴屏幕最左、
  在棋盘下缘之外,整体比旧版更紧凑
- **局前不识别**：没点「开局」时识别循环不启动——不抓帧、不跑 CNN、
  不提示「识别不稳定」;引擎仍在后台静默预热,点开局后首推更快
- **多步确认（2026-10-26）**：一次落定里出现 3-4 手、且有多种合法解释时，
  悬浮窗会弹确认框，直接列出候选序列（如 `① 红 车四进一 → 黑 卒7进1`），
  点一条即按它记账；20 秒未选按第 1 条。平台（中间稳定帧）能唯一确定时
  不弹窗、自动记账
- **推荐区**：三条候选,普通=灰色序号,打吃=藏蓝「吃」徽章,
  将军=朱红「将」徽章;首行常年显示上一手（「你：炮二平五」/「对手：…」）。
  **每个局面只出一次结果**（约 1.2s 搜索），不会先出一批再换一批；
  引擎还在加载时正文显示「引擎预热中 Xs」
- **浮窗纠错（2026-10-22）**：发现识别错/漏一手时点「纠」→ 四个下拉
  `[红/黑棋子][起始纵线 1-9][进/退/平][目标纵线或步数]`（纵线统一从
  屏幕右侧数 1-9）。程序自动判断：能从当前棋谱局面走=「补上这一步」,
  只能从上一手局面走=「改掉上一手」，确定后立即写回棋谱/锚点并重出推荐;
  弹窗里还有「撤回上一手」。非法着法按钮会变灰并提示
- **降级条**：识别不稳定时出现琥珀色提示 +「重试识别」按钮,稳定后自动
  恢复候选。若棋子"无故消失"或走子对不上,不会再自动清谱/重锚,而是
  保留棋谱并强制重推;持续异常请用「纠」或「重试识别」放行
- **下一局**：复盘完成后「结」会变成朱红「下一局」,点它清棋谱开新局,
  按钮复位为「结」

## 4. 对局实况（核对/纠正识别错误）

对局进行中,从悬浮窗标题栏点「**♟**」(或主界面「对局实况 →」)进入实况页
(1 秒自动刷新):

- **棋盘**:渲染源按可信度自动切换——棋谱与识别**一致**时按棋谱推演摆盘;
  **不一致或本局尚无棋谱**时切为**识别直读盘**(棋谱一旦被幽灵步污染,
  推演会画出"棋子凭空消失"的假盘)。**可手动纠正**:点棋子再点目标格即可
  移动,改完自动按纠正局面重算推荐(只影响显示,不改棋谱)
- **识别对照**:识别局面与棋谱不一致时朱红提示(=识别中途出过错),
  一致则灰字 ✓
- **推荐招法**:当前候选(带威胁标签:将军/叫将/吃/打吃)
- **棋谱**:逐步着法(序号+红黑+中文),对着 JJ 的行棋记录逐条对照

## 5. 复盘与知识库

- 对局中任意时刻点「结」（棋谱非空）→ 弹窗询问「**是否复盘**」：
  - **复盘**：棋谱入库后**立即回到局前**（可以马上开下一局），复盘在后台跑
    （实战期间在每个局面边界让路，共用引擎时单局面 1500ms；完成后发通知）。
    悬浮窗正文会显示「后台复盘 x/y」，开新局后不再打扰推荐区
  - **不复盘**：只封存棋谱，对局复盘列表里标「未复盘」
  - **取消**：什么都不做，留在当前对局
- 复盘分析过的局面自动进知识库:同一局面再次实战出现时,悬浮窗
  秒回（「库」着法）,不占引擎
- **复盘列表状态**（主界面「对局复盘」）：`复盘 x/y`=正在进行、
  `等待复盘`=已排队、`未复盘`=封存时选择不复盘、`复盘中断`=进程被杀/
  异常中断（日志 `mark interrupted game=N`）。复盘进行中列表每秒刷新
- 复盘结束（或复盘失败/无棋谱）后按钮回到「开局」；点它以当前盘面
  开始新局，旧棋谱不会被继续追加

## 6. 样本与标注（重训用，2026-10-26）

- 歧义确认 / 四下拉纠错后，会把这帧 PNG + 确认后的盘面落盘到
  `files/labels/<时间>-<类型>/`（`frame.png` + `meta.json`），并在
  `files/labels/index.jsonl` 追加索引；最多保留 200 个目录
- 被拒的识别帧仍在 `files/dump/`，现在每张 PNG 旁边有同名 `.json`
  记录拒帧原因与期望局面，便于筛选硬负样本
- 日志也可在 App 主界面点「**导出日志**」→ 复制到系统 `下载/象棋助手日志/`,
  不需要 adb（真机排障最方便）
- 拉取（整目录）：

```bash
adb -s <序列号> exec-out run-as com.cheese.assistant   tar -C files -cf - labels dump > "labels.tar"
```

## 7. 卡死 / 异常排障（内置日志）

所有业务日志自动落盘（`files/logs/app-MMdd-HHmmss.log`,保留最近 4 份,
崩溃堆栈也写在内）。卡死后**不要杀进程**,直接拉日志:

```bash
# 列出日志
adb -s <序列号> shell "run-as com.cheese.assistant ls -t files/logs"
# 导出最新一份
adb -s <序列号> exec-out run-as com.cheese.assistant \
  cat files/logs/<文件名> > 弈枰日志.txt
```

把文件发给分析。识别卡死时悬浮窗降级条通常会直接显示原因
（「识别循环异常：…」）。

## 8. 对局结束时

JJ 弹出「局终/结算奖励」后,深色面板盖住棋盘,悬浮窗会先「识别不稳定…」,
约 18 秒后提示升级为**「画面疑似对局已结束或被弹窗遮挡——若已结束点『结』
复盘,点『再来一局』回棋盘自动恢复」**。照做即可:

1. 点悬浮窗「结」→ 封存并复盘本局(棋谱在应用内部,弹窗遮挡不影响)
2. 复盘完成后按钮回到「开局」;回 JJ 点「再来一局」开新局
3. 新棋盘出现后点悬浮窗「开局」开始记账(局前不识别;若从未点「结」,
   识别循环仍在,会继续自动出推荐)

## 9. 已知限制

- 重装/杀进程后截屏授权失效,必须重走第一节流程(系统限制)
- **中途加入对局可用**:切到正在进行的对局，点悬浮窗「开局」即以当前
  画面建立局面,随后按落定确认期出推荐（局前不点开局不会识别）
- 离开 JJ 对局页(主界面/聊天/结算页等)识别自动暂停且保留锚点,
  回到对局页自动恢复;〈使用情况访问〉未授权时靠边条指纹判断,可能略慢
- 每步需**连续两帧一致**才落定,对方走子到出推荐通常 1-2s;入场动画
  未结束时会继续等,超时(30s)强制接受当前画面
- 校准按目标 App 区分,但当前固定只支持一个目标(TARGET_APP="default")
- 悬浮窗别拖进棋盘识别区(y≈455~1530),会遮挡识别出持续 unknown
- JJ 让红方在屏幕上方时(我方执黑)识别会自动上下翻转,无需手动干预;
  若执方显示反了,点标题栏「黑/红」手动纠正
