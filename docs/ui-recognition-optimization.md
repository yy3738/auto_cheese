# 功能优化：蓝白主题 / 悬浮窗收起 / 下一局 / 打吃标志 / 识别降级与回合修复

> 2026-10-12 拷问式访谈（grill-me）产出。所有设计点均已与用户逐条确认。

## 1. 蓝白主题

### 色板（用户指定）

| 用途 | 色值 |
|------|------|
| 悬浮窗背景 | rgba(248,250,253,0.85) → ARGB `0xD9F8FAFD` |
| 主色/强调（按钮、高亮、标记） | `#234B94` 藏蓝 |
| 正文文字 | `#1A1A1A` |
| 边框细线 | `#CBD5E1` |
| 次要文字 | `#64748B` |

### 应用范围

- 主界面、悬浮窗（OverlayView）、复盘界面（ReviewActivity）、BoardView 全部套用色板。
- **棋子颜色不动**（红子红字、黑子黑字），藏蓝只做 UI 强调（选中高亮/按钮/提示标记）。
- 设计原则（源自 frontend-design skill）：藏蓝只出现在需要行动/重点的地方；一处目的性动效（收展过渡+轮到你脉冲），不做装饰性动画。

## 2. 悬浮窗侧面收起/展开

- 收起形态：**A 小圆点方案**（用户选定）。
- 圆点带状态色：轮到你 = 藏蓝实心；对手回合 = 灰白描边。
- 收展过渡动效 + "轮到你"脉冲动效，仅此一处动效。
- 自动收展不做，纯手动。

## 3. 下一局功能

- 封存（点"结"）后悬浮窗切到"复盘 + 开始下一局"状态。
- 点"下一局"：清空棋谱 + 悬浮窗状态机归位。
- **动机**：自动 reset（AssistantService 连续 3 次 implausible 兜底）有时执行失败，需要显式手动保险。自动 reset 逻辑保留。

## 4. 打吃标志（序号即徽章）

- **定义**：模拟走推荐着法后，下一步能吃到对方任意子 = 打吃；吃王（将军）优先显示为"将"。
- **形态**：序号即徽章，零新增元素：
  - 有威胁：序号变藏蓝实心圆 + 白字；
  - 将军：同上 + 外圈（更重）；
  - 无威胁：灰蓝细描边空心圆（弱化）。

## 5. 识别降级显示 + 手动重触发

- 识别不可信期间（动画/异常），推荐区**显式降级**：整体变灰 + 状态小字（"识别中…"/"识别不稳定"），恢复后自动回满色。
- 降级时出现"手动重触发识别"按钮（藏蓝描边样式），点一次强制重走"等稳定→识别→校验"流程；正常状态不显示。
- **推荐区顶部常驻一行上次走子**：`对手：炮8平7` 式小字（次要灰），降级时保持可见作为局面锚点。

## 6. 回合突然变红 bug（已定位根因）

- 现象：用户执黑，悬浮窗突然显示"红方回合"并给红方推荐。
- **根因**（2026-10-12 现场 logcat 抓获）：`BoardWatcher.bottomSideIsRed()` 只扫屏幕矩阵 row9→row8 找王。残局用户把將走到九宫顶线（row7，合法位置）时扫描落空 → 静默 `fallback red` → userIsRed 翻转 → 执方/回合/推荐对象全错。间歇性根源：跟着王的位置走。
- **修法**：改为找双王各自的行，**行号大（靠屏幕下方）者为用户**；删除 `fallback red` 静默兜底（双王俱在校验已保证局面里有王，无须兜底）。

## 7. 下一批（本轮不做）

- **摆子修正模式**：主界面入口 → 预填最近识别局面为底稿 → 点选棋子可删除/换子/移动，支持撤回 → 求推荐。定位是"识别坏时的人工纠错通道"，非空白摆子录入。
